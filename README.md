# Inkvoice - Creative Agency Website Template

A fully static, multi-page website template inspired by the Inkvoice creative blog/magazine theme. This template features modern editorial aesthetics, large typography, bold imagery, and clean grid layouts with advanced animations and interactions.

## 🎨 Features

### Core Functionality
- **Multi-page Static Website**: Home, About, Services, Portfolio, Blog Listing, Single Blog, and Contact pages
- **Fully Responsive**: Optimized for mobile, tablet, and desktop devices
- **Modern Semantic HTML5**: Clean, accessible markup structure
- **No Backend Required**: Pure HTML, CSS, and JavaScript
- **SEO Optimized**: Proper meta tags and semantic structure

### Design & Visual Effects
- **Custom Animated Cursor**: Dot + trailing ring with hover expansion and magnetic effects
- **Page Load Animations**: Smooth loader with fade transitions
- **Section Reveal Animations**: Different animation styles for each section on scroll
- **Hero Video Background**: Autoplay, muted, loop video with parallax overlay
- **3D Floating Divs**: Multiple animated gradient blobs with depth effects
- **Glassmorphism Cards**: Modern glass-like design elements
- **Animated Gradients**: Dynamic color transitions throughout

### Interactive Elements
- **Scroll Progress Indicator**: Visual progress bar showing page scroll position
- **Sticky Header**: Blur effect with hide/show on scroll
- **Back to Top Button**: Animated button with smooth scrolling
- **Hover Distortion Effects**: Advanced image hover animations
- **Particle Background**: Subtle animated particle system
- **FAQ Accordion**: Smooth expandable FAQ sections
- **Form Validation**: Animated contact form with floating labels

## 🚀 Getting Started

1. **Download/Clone** the template files
2. **Open** `index.html` in your web browser
3. **Customize** the content, colors, and images to match your brand
4. **Upload** to your web server or hosting platform

### Customization Guide

#### Colors & Theme
Edit the CSS variables in `css/style.css`:

```css
:root {
  --primary: #6366f1;
  --secondary: #ec4899;
  --accent: #14b8a6;
  /* ... more variables */
}
```

#### Fonts
Replace Google Fonts imports in the `<head>` section of each HTML file.

#### Content
Update text content, images, and links throughout the HTML files.

#### Logo
Replace the logo text or add your own logo image in the header.

## 📱 Responsive Design

- **Tablet**: 768px - 1024px
